# 💌 Uma Surpresa Pra Você

Um site-jogo fofo com 3 desafios e um presente no final:

1. **Chuva de Amor** – arraste o gatinho 🐱 para pegar 20 coisinhas fofas (cuidado com as nuvens de chuva 🌧️).
2. **Memória Fofa** – encontre os 8 pares de cartas.
3. **Quiz do Coração** – 3 perguntinhas (só tem uma resposta certa 😉).
4. **🎁 O presente** – toque 3x na caixa e descubra a surpresa.

É só abrir o `index.html` no navegador (funciona no celular também). Para publicar, ative o GitHub Pages no repositório.
